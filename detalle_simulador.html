Simulador de Planificación de Procesos

  • Fecha de inicio: 05 de Mayo de 2026
  • Autores Principales: Mauro Lombardo, Facundo López, Ana Silva

Descripción

El Simulador de Planificación de Procesos es una herramienta didáctica desarrollada para facilitar el aprendizaje práctico en la cátedra de Sistemas Operativos de la carrera Analista Programador Universitario. Esta aplicación permite a los estudiantes visualizar de manera dinámica cómo el sistema operativo administra el tiempo de CPU entre múltiples procesos concurrentes.

Los usuarios pueden configurar escenarios personalizados definiendo parámetros como el tiempo de llegada, las ráfagas de CPU y la prioridad de cada proceso. El sistema procesa esta información y genera en tiempo real un Diagrama de Gantt interactivo, demostrando el comportamiento de algoritmos clásicos como FCFS (First Come, First Served), SJF (Shortest Job First), Round Robin y Planificación por Prioridades. Además, calcula automáticamente métricas clave como el tiempo de espera promedio y el tiempo de retorno.
