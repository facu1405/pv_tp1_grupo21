Huerta Escolar Inteligente

  • Fecha de inicio: 15 de Junio de 2023
  • Autores Principales: Javier Tolaba, Cristian Romero, Brenda Cruz

Descripción

La Huerta Escolar Inteligente es un sistema de monitoreo y riego automatizado orientado a las escuelas agrotécnicas de la provincia. El proyecto busca integrar conceptos de programación y electrónica básica para optimizar el uso del agua y mejorar el rendimiento de los cultivos didácticos. Mediante el uso de placas microcontroladoras y sensores de bajo costo, el sistema recopila datos del entorno físico en tiempo real.

El software procesa la información de humedad del suelo, temperatura ambiente y exposición solar para tomar decisiones autónomas sobre la activación de las bombas de riego. Además, toda la información recolectada se envía a una base de datos centralizada, permitiendo a los alumnos y docentes visualizar gráficos históricos de las variables climáticas a través de una interfaz web, facilitando así el análisis y la toma de decisiones para futuras siembras.
